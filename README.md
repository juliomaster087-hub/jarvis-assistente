# Jarvis Assistente

Página inicial do projeto Jarvis Assistente, feita com HTML, CSS e JavaScript puro.

## Publicar com GitHub Pages

1. Abra **Settings** do repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/(root)**.
5. Clique em **Save**.

Depois que o GitHub Pages concluir a publicação, o endereço do site aparecerá nessa mesma página de configurações.
